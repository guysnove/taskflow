# TaskFlow 2.0.0 — release notes

2026-11-23. TaskFlow v1 (the end of Course 1) engineered into TaskFlow v2 (Course 2). Full review: [../review/2026-11-23-taskflow-2.0.md](../review/2026-11-23-taskflow-2.0.md).

## For users

- **Task dependencies** ("blocked by"), with a notification when a task is unblocked; an **overdue** filter; due-date reminders.
- **Notifications** in the app and by email; email is sent reliably (an outbox with retries), and can be turned off in Notifications › Settings.
- A faster task list: **paged**, 50 tasks a page.

## For API clients

- Requests are compatible with 1.x. New: optional paging on `GET /api/tasks` (`page`, `pageSize`, an `X-Total-Count` header);
  an `Idempotency-Key` header for safe retries of `POST`.
- **Changed:** every error is now a problem details document (`application/problem+json`), including 401, 404 and 429.
  See [../api/README.md](../api/README.md).

## For operators

- Container image (non-root) and Compose files ([../containers.md](../containers.md)); `Deploy/deploy.sh` with automatic rollback.
- `/health` (alive) and `/health/details` (every check, JSON); metrics and traces through OpenTelemetry (`OTEL_EXPORTER_OTLP_ENDPOINT`);
  runbooks and alerts in [../operations.md](../operations.md). New settings: [../configuration.md](../configuration.md).
- Database migrations run at startup; they only add tables, columns and indexes, so 1.x can be restored from a backup if needed.

## For developers

- Four projects with enforced boundaries; 263 tests plus an end-to-end test; coverage gate; format and analyzers in CI.
- `tools/review.sh` (the automated half of a review) and `tools/smoke.sh` (a first user's path against a running TaskFlow).
